01 / voluntario

Resurrección del Chromebook N22

Transformé un Lenovo N22 con ChromeOS obsoleto en una máquina dual-boot con Windows 11 Pro y Arch Linux + Hyprland — todo en un eMMC de 30 GB.

Voluntario Arch Linux Hyprland Hardware real Dual-boot
detalle ↓

El reto

Un Lenovo N22 con ChromeOS descontinuado que ya no recibía actualizaciones. El hardware seguía funcionando — el software lo limitaba. El objetivo: convertirlo en una máquina completamente funcional sin tirar el equipo.

El problema técnico real

El disco es un eMMC soldado de solo 30 GB. Instalar Windows 11 Pro (con sus requisitos mínimos) y Arch Linux con Hyprland en ese espacio requirió una planificación cuidadosa del particionado y decidir qué instalar en cada sistema para que ambos fueran viables.

Proceso

  • Análisis del hardware y compatibilidad de drivers
  • Desbloqueo del firmware del Chromebook
  • Diseño del esquema de particionado en 30 GB
  • Instalación de Windows 11 Pro con ajuste de espacio
  • Instalación manual de Arch Linux desde cero
  • Configuración de Hyprland como compositor Wayland
  • Configuración del bootloader dual-boot

Resultado

Funcionó perfectamente. Dual-boot operativo entre Windows 11 Pro y Arch Linux con Hyprland. Todo documentado.

02 / académico ampliado

Instalación y configuración de Endeavour OS

Práctica de instalación del módulo SOM. Elegí Endeavour OS — basada en Arch — por su proximidad al sistema real. Instalada en hardware real.

Arch-based Hardware real CC BY-NC-SA 4.0
detalle ↓

Contexto

Práctica de instalación del módulo SOM (1º SMR). Opté por Endeavour OS — distribución Arch-based con instalador gráfico pero sin ocultar la estructura del sistema — por querer profundizar más allá del temario.

Por qué Endeavour OS

Arch Linux puro requiere instalación completamente manual desde TTY. Endeavour mantiene esa filosofía con un instalador gráfico, ideal para profundizar en cómo funciona el sistema real sin perderse horas en el particionado.

03 / personal · open source

Instalador Automático de Arch Linux

Script Bash de producción: 3 fases de configuración interactiva, cifrado LUKS2, soporte BTRFS con subvolúmenes, 4 kernels, 6 entornos de escritorio y navegación hacia atrás sin perder estado. Arch Linux completo en 5–10 minutos.

Open Source Bash LUKS2 BTRFS Arch Linux set -euo pipefail
detalle ↓

El problema real

Instalar Arch Linux manualmente implica más de 30 comandos ejecutados en orden exacto: particionado, formateo, montaje, pacstrap, arch-chroot, configuración del bootloader, red, locale, zona horaria, usuarios... Y un solo error en cualquier punto te obliga a empezar desde cero. Hacerlo repetidamente en diferentes máquinas es tiempo perdido de forma sistemática.

La solución: un instalador de producción

Un único archivo install.sh con set -euo pipefail (ejecución estricta, sin fallos silenciosos) que recorre tres fases de preguntas antes de tocar el disco. Cualquier pregunta admite pulsar < + Enter para volver al paso anterior sin perder la configuración ya completada.

Fase 1 — Sistema Base (11 decisiones)

  • Detección automática de discos con modelo y tamaño (lsblk)
  • UEFI vs BIOS/Legacy detectado automáticamente desde /sys/firmware/efi
  • Swap configurable con validación de formato (8G, 512M) y comprobación de que cabe en el disco
  • Cifrado LUKS — LUKS2 + Argon2id para systemd-boot, LUKS1 + SHA-256 para GRUB (por compatibilidad). La swap cifrada usa PARTUUID para evitar arranques lentos
  • Sistema de archivos: ext4 (clásico) o btrfs con subvolúmenes automáticos (@, @home, @snapshots, @log)
  • Partición /home separada (solo ext4); el espacio restante se asigna automáticamente
  • Hostname, zona horaria (validada contra /usr/share/zoneinfo/), idioma y distribución de teclado
  • Selección de kernel: linux · linux-lts · linux-zen · linux-hardened
  • Bootloader: GRUB (UEFI + BIOS) · systemd-boot (solo UEFI)

Fase 2 — Usuario y Seguridad

  • Nombre de usuario con creación automática en grupos wheel, audio, video, storage
  • Contraseña de root y de usuario con entrada oculta y doble confirmación obligatoria

Fase 3 — Entorno Gráfico y Extras

  • Driver de vídeo: Intel · AMD · NVIDIA · VirtualBox · VMware · Ninguno (servidor headless)
  • Entorno de escritorio: GNOME · KDE Plasma · XFCE · Hyprland · i3-wm · Todos · Ninguno
  • AUR helper: paru · yay · ninguno
  • Dotfiles: URL de repositorio git + script de instalación definido por el usuario
  • SSH: habilita sshd al arranque con un solo paso

Ingeniería interna destacada

  • Máquina de estados: HISTORIAL[] + PASO permiten navegar hacia atrás sin perder datos de cada fase
  • UI coloreada completa: funciones log(), warn(), error(), step(), pick() con ANSI para una experiencia visual profesional en TTY
  • Validación real: verifica existencia del disco, formato de tamaños, que el swap no supera el espacio disponible y que las contraseñas coinciden
  • Zero configuración manual posterior: el sistema arranca completamente listo incluyendo entorno gráfico, AUR helper y dotfiles personales
